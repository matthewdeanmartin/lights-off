# Lights Off

**Lights Off** is a keyboard-driven, screen-reader-friendly Mastodon client for Windows and macOS.
It is a fork of [Quinter](https://github.com/QuinterApp/Quinter), a Twitter client that was
redesigned for the Mastodon network.

The application requires no mouse. Every action is reachable by keyboard shortcut, and all
content is routed through the platform screen reader so that blind and low-vision users can
browse timelines, post, boost, reply, and manage their account without leaving the keyboard.
