# Keyboard reference

On Windows the modifier key shown as **Ctrl** maps to the **Control** key.
On macOS it maps to the **Command (⌘)** key unless stated otherwise.

## Application

| Action | Windows | macOS |
|---|---|---|
| Manage accounts | Ctrl+A | Cmd+A |
| Global options | (menu) | Cmd+, |
| Exit | Alt+F4 | Cmd+Q |
| Toggle window visibility | Ctrl+Alt+Win+T | — |
| Quit (always-on) | Ctrl+Alt+Win+Q | — |
