# lights-off

lights-off is a light-weight, accessible Mastodon client for Windows and Mac, built with wxPython.

It is a fork of [Quinter](https://github.com/QuinterApp/Quinter), a Twitter client, converted to support Mastodon.

## Running

```batch
git clone https://github.com/QuinterApp/Quinter
cd Quinter
pip install -r requirements.txt
python lights-off.pyw
```

## Building

```batch
git clone https://github.com/QuinterApp/Quinter
cd Quinter
pip install -r requirements.txt
build.bat
```

## First run

On first launch you will be prompted for your Mastodon instance URL (e.g. `https://mastodon.social`) and will complete an OAuth browser flow to authorise the app.
